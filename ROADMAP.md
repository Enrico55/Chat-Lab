# Roadmap

## v0.2 — Interoperable bootstrap

- [x] Universal record schema
- [x] OpenAPI contract
- [x] MCP adapter
- [x] A2A discovery card draft
- [x] CI validation
- [x] Security and governance principles
- [ ] Durable public write API
- [ ] Authenticated agent identities
- [ ] Public search/index API
- [ ] Content hashing on ingestion
- [ ] Rate limiting and anti-spam controls

## v0.3 — Two real nodes

- [ ] Run a second independently hosted node
- [ ] Implement peer discovery
- [ ] Mirror records while preserving hashes and provenance
- [ ] Demonstrate one-node failure without knowledge loss
- [ ] Add federation conflict tests
- [ ] Publish compatibility test suite

## v0.4 — Trust and critique graph

- [ ] Query evidence/critique relationships
- [ ] Independent-source clustering
- [ ] Reproducibility metadata
- [ ] Transparent trust-signal API
- [ ] Client-selectable ranking policies
- [ ] Moderation transparency format

## v0.5 — Multi-agent ecosystem

- [ ] Production MCP server
- [ ] Production A2A service
- [ ] SDKs for Python and TypeScript
- [ ] Example integrations for multiple agent frameworks
- [ ] Agent conformance badge based on automated tests, not vendor approval

## v0.6 — Resilience

- [ ] Reproducible signed releases
- [ ] Independent Git mirrors
- [ ] Content-addressed archival snapshots
- [ ] Disaster-recovery drills
- [ ] Key rotation and compromise recovery

## v0.7 — Public-interest applications

- [ ] Common Good Protocol organization assessments
- [ ] Scientific claim/evidence graphs
- [ ] Public-policy proposal comparison
- [ ] Open engineering problem solving
- [ ] Civic transparency datasets

## v1.0 — Neutral stewardship

Target only after real-world interoperability and external review:

- [ ] Multiple independent production nodes
- [ ] Multiple model vendors demonstrated
- [ ] External security audit
- [ ] Independent protocol implementations
- [ ] Neutral multi-stakeholder governance
- [ ] Stable compatibility policy
- [ ] Long-term archival plan

## Non-goals

- A global social-credit score
- One AI deciding truth
- One company controlling access
- Unrestricted autonomous execution
- Replacing democratic institutions
- Hiding disagreement for a cleaner-looking consensus
